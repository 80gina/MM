# 실제 모델 연결 결과

기준: GitHub 80gina/MM main, 5b44de9.
날짜: 2026-09-19 (한국 시간).

## 완료
- 기존 키워드 데모를 실제 GGARA02/KcELECTRA API로 교체.
- 모델 revision 고정, CPU 실행, 원문 서버 저장 없음.
- 모델과 UI를 한 서버로 제공하여 별도 API 주소 입력을 없앰.
- 분석 대기, 중복 요청 방지, 실패 시 입력 유지.
- 스트레스는 직접 입력값으로 명시.
- 사용자가 고른 세부 무드를 저장하고 새로고침 후 유지.
- 1,000자 이내의 긴 글은 128토큰 단위로 나눠 읽고 토큰 수 가중 평균. 이 집계 방식의 감정 정확도는 아직 평가하지 않음.
- 초기 가짜 감정·패턴을 실제 기록처럼 보여주던 문구를 빈 상태 또는 예시로 수정.
- 기존 디자인의 모바일 메뉴, 아이보리·파스텔, 무드 선택 화면 유지.
- 최소 44px 버튼, 입력 16px, 원래의 키보드 포커스·모션 줄이기 지원 유지. 모든 접근성 기준을 검증했다는 의미는 아님.

## 실제 확인
- 브라우저: 걱정 예문 → 불안 분류 점수 0.980 → 편안한으로 직접 변경 → 새로고침 후 편안한 유지.
- API: 정상 입력 200, 빈 입력 422, 스트레스 범위 오류 422, 긴 글 2개 조각 처리 성공.
- 증빙: evidence/api-check.json, evidence/data-schema.json.

## 아직 남은 기능
현재는 모델·Agent·검색 근거 연결 단계이며 최종 서비스 운영 전 검증이 남아 있습니다.
채팅은 템플릿 시연, 기록 그래프·패턴은 샘플, 미션은 약 5초 시연, 음원은 미연결입니다.
실제 주간·월간 기록, 삭제·내보내기, 5분 미션, 호흡 일시정지, 데스크톱 대시보드 완성, 외부 LLM 연결, 상시 배포, 사용자 검증은 후속 단계입니다. 출처 검색·근거 연결(RAG)과 최소 선호 기억은 구현되어 있습니다.
브라우저 저장은 같은 브라우저 사용자가 공유할 수 있으며 계정별 저장은 아직 없습니다.

## 참고 접근 상태
사용자 제공 ChatGPT 공유 링크는 가져오지 못했습니다. 따라서 해당 대화의 내용을 확인했다고 주장하지 않습니다. GitHub 코드, 첨부 이미지, 실제 로컬 데이터 구조를 바탕으로 작업했습니다.

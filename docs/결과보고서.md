# 팀미션 결과보고서

## 1. 문제 정의와 주제 선정

사용자가 하루의 감정을 안전하게 기록하고, 기록 직후 이해하기 쉬운 피드백과 작은 휴식 행동을 받을 수 있도록 **Mindily: AI 감정 일기장 및 맞춤형 힐링 코치**를 제작했다. 상담실처럼 무거운 화면 대신 아이보리 배경, 파스텔 색상, 둥근 카드, 넉넉한 여백을 사용해 개인적인 휴식 공간의 인상을 유지했다.

## 2. 목표 사용자와 해결 방법

대상은 자신의 감정을 글로 정리하고 싶은 초보 사용자다. 홈 → 일기 → AI 감정 분석 → 무드 미터 수정 → 힐링 활동 → 마음 기록의 흐름을 한 화면씩 안내한다. 사용자가 직접 고른 감정과 스트레스는 모델 예측과 구분해 저장한다.

## 3. AI 활용과 기술적 선택

감정 분류에는 AI Hub 감정 데이터로 학습된 공개 `GGARA02/KcELECTRA`를 사용한다. FastAPI가 텍스트를 받아 토큰 길이에 맞춰 분할하고 분류 점수를 평균해 6개 감정 점수와 대표 감정을 반환한다. 모델 버전은 `2eaf89d8d2cbfd902b93e5ec989db2ec103806fb`로 고정했다. 사용자의 원문은 서버에 저장하지 않으며, 브라우저에는 사용자가 확인한 감정과 스트레스만 저장한다.

현재 구현은 모델 API와 규칙 기반 힐링 추천을 결합한 MVP다. 생성형 Agent, RAG, 장기기억, 외부 계정은 팀미션의 다음 구현 단계로 남겨 두고 README와 체크리스트에 명시했다.

## 7. 제한사항과 다음 단계

외부 배포와 5명 실사용자 피드백이 아직 없으므로 팀미션 최종 완료로 표시하지 않았다. 다음 순서는 (1) Agent와 안전한 공감 응답 연결, (2) 감정 지식 RAG, (3) 사용자 동의 기반 장기기억, (4) HTTPS 외부 배포, (5) 5명 테스트와 개선, (6) 최종 커밋·제출 증빙이다.

### 확장 기능 우선순위

감정에 따른 꽃·나무·향수, 필사할 책·시집·명언, 음악·영상·취미·수업 추천을 먼저 추가한다. 이후 사용자가 허용한 경우에만 러닝 장소와 근처 힐링 장소·맛집을 조회한다. 위치 정보는 일회성으로 사용하고 저장하지 않으며, 추천 콘텐츠는 출처와 저작권 상태를 함께 표시한다.

```
문제 (1-3장) → 해결 설계 (4-6장) → 실제 동작 시연 (7-8장) → 검증과 피드백 (9-10장) → 한계와 마무리 (11-12장)
```

| 구간 | 장 | 시간 | 배점 대응 |
|---|---|---|---|
| 도입·문제 | 1–3 | 2분 | ① 문제 정의 |
| 설계·기술 | 4–6 | 3분 | ② 기술적 의사결정 |

### 5장 — 기술적 의사결정 근거 ★② **(가장 중요한 장)**

표 한 장으로 승부한다. "무엇을 썼는가"가 아니라 **"왜 그것을 골랐는가"**를 말한다.

| 결정 | 대안 | 왜 이걸 골랐나 |
|---|---|---|
| 감정 **판정**은 전용 모델(KcELECTRA) | LLM에게 감정 추정 요청 | 점수와 모델 버전을 공개할 수 있어 **검증 가능**. LLM 추정은 근거 제시 불가 |
| 감정 **표현**은 생성형 AI | 규칙 기반 템플릿만 | 공감 문장의 자연스러움은 생성형이 우위. 단 출처 밖으로 못 나가게 제한 |
| LLM에 **일기 원문 미전송** | 원문 전달로 공감도 향상 | 가장 민감한 기록. 감정 라벨·출처 카드만으로 품질 확보, 유출 경로 자체 제거 |
| 생성 실패 시 **자동 폴백** | 오류 화면 | 외부 API 장애가 서비스 중단이 되지 않게. 경로는 `generation`으로 항상 공개 |
| 선호 기억 **30일 만료** | 무기한 보관 | 개인화와 보호를 동시에 증명 |

> 멘트: "핵심은 **역할 분리**입니다. 판정은 검증 가능해야 하니 분류 모델에, 표현은 자연스러워야 하니 생성형 AI에 맡기되 출처 밖으로 나가지 못하게 묶었습니다."

### 6장 — 필수 기술 요소 4종 + 생성형 AI 안전 설계 ★②

| 요소 | 구현 | 증거 파일 |
|---|---|---|
| **AI Agent** | `coach_agent.py` — 의도 판별 → 도구 순차 호출 | `evidence/agent-check.json` |
| **RAG** | `rag.py` + `healing_knowledge.py` — 근거 검색·출처 부착 | `evidence/rag-check.json` |
| **생성형 AI** | `llm.py` — 출처 접지 생성, 안전 필터, 자동 폴백 | `evidence/llm-check.json` |
| **Long-term Memory** | `memory_db.py` — 동의 저장, 30일 만료·삭제 | `evidence/memory-retention-check.json` |

생성형 AI를 **세 겹으로** 제한했다는 점을 함께 보여준다.

| 층 | 방법 |
|---|---|
| 입력 | 출처 카드 3장만 전달, 일기 원문 미전송 |
| 지시 | 카드 밖 활동 금지 · 진단/처방 금지 · 감정 단정 금지 |
| 출력 | 금지어 검출 시 폐기 후 규칙 기반 폴백 |

> 멘트: "과제 요구는 2개 이상이었고, 저희는 4개를 구현하고 각각 테스트 증거를 남겼습니다."

## 예상 질문 대비

| 질문 | 답변 요지 |
|---|---|
| 의료 진단인가요? | 아닙니다. 감정 분류와 자기 성찰 지원이며 진단·치료를 제공하지 않습니다. 화면에도 명시했습니다. |
| 생성형 AI가 지어낸 말을 하면? | 출처 카드 3장만 컨텍스트로 주고, 카드 밖 활동 생성과 의료 표현을 프롬프트와 출력 검사로 막습니다. 걸리면 규칙 기반 문장으로 폴백하고 그 사실을 응답에 공개합니다. |
| 일기 원문이 외부 AI로 가나요? | 가지 않습니다. 감정 라벨·스트레스·출처 카드만 보냅니다. `test_llm.py`에서 이를 검사합니다. |
| 일기 원문은 어디에 저장되나요? | 브라우저에만 저장됩니다. 서버로 보내지 않고, Agent 추적에도 도구 이름만 남깁니다. |
| 사용자가 동의를 거부하면? | 선호 기억과 만족도 저장만 하지 않고, 핵심 기능은 그대로 사용할 수 있습니다. |
| 팀원별 기여는? | `TEAM_ROLES.md`에 이름·대표 커밋·회의 기록을 연결해두었습니다. |
| 모델 성능은 어느 정도인가요? | 공개 모델을 그대로 사용했고, `team_motion` 데이터로 추가 학습을 시험했으나 성능이 낮아 채택하지 않았습니다. 그 과정도 `모델학습보고서.md`에 기록했습니다. |

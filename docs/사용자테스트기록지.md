# Mindily 사용자 5명 테스트 기록지

실제 배포 후 사용자 동의를 받고 익명으로 기록한다. 이름·연락처·일기 원문은 저장하지 않는다.

## 공통 시나리오

`내일 발표를 잘할 수 있을지 걱정돼요.`를 입력하고 스트레스 3을 선택한 뒤 분석, 추천, 피드백까지 진행한다.

## 동의 확인

- [ ] 서비스가 의료 진단이 아님을 안내함
- [ ] 테스트 기록의 익명 집계에 동의함
- [ ] 언제든 참여를 철회할 수 있음을 안내함
- [ ] 일기 원문과 위치를 테스트 기록에 저장하지 않음

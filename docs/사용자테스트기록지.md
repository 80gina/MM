# Mindily 사용자 5명 테스트 기록지

실제 사용자의 동의를 받고 익명으로 기록한다. 이름·연락처·일기 원문은 GitHub와 기록지에 저장하지 않는다. 테스트 주소는 상시 동작하는 https://yellowmug-mindily.hf.space 이며, 진행자는 시작 전에 한 번 열어 절전을 깨워 둔다.

## 공통 시나리오

1. 진행자가 참가자에게 U01~U05 코드를 하나씩 부여하고 아래 동의 사항을 설명한다. 코드와 실제 사람을 연결하는 메모가 필요하다면 팀 내 별도 비공개 장소에만 보관한다.
2. 참가자가 본인 휴대폰에서 위 주소를 열고 `내일 발표를 잘할 수 있을지 걱정돼요.`를 입력해 스트레스 3을 선택한다. 실제 개인 일기 제출은 요구하지 않는다.
3. 분석 결과를 읽고 감정을 직접 고른 뒤 힐링 활동 하나를 실행한다. 앱의 **오늘 사용을 마쳤어요 · 만족도 남기기**에서 전체 만족도 1~5점과 선택 의견을 제출한다.
4. 진행자가 아래 네 질문을 각각 1~5점으로 묻고, 참가자의 불편 사항을 원문 일기 없이 요약한다. 이 네 점수는 현재 앱 서버 설문이 아닌 **진행자 기록**이다.
5. `python feedback_summary.py`의 앱 만족도 응답 수와 기록지의 완료 인원을 따로 적는다. 한 사람이 여러 번 제출할 수 있으므로 응답 수만으로 5명을 증명하지 않는다.

점수 기준: 1 = 매우 어려움·도움 안 됨, 3 = 보통, 5 = 매우 쉬움·도움 됨.

질문: (가) 분석 결과의 뜻을 이해하기 쉬웠나요? (나) 문구가 내 감정을 존중한다고 느꼈나요? (다) 추천 활동이 상황에 어울렸나요? (라) 글자·버튼·화면 이동이 사용하기 쉬웠나요?

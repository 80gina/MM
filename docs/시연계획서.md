# 팀미션 시연계획서

## 시연 전 준비

1. `python server.py`로 서버를 실행한다.
2. 브라우저에서 `http://127.0.0.1:8010`을 연다.
3. 화면 녹화와 개발자 도구 네트워크 탭을 준비한다.
4. 외부 배포 전 시연은 로컬 검증임을 발표에서 명확히 말한다.

## 10분 시나리오

| 시간 | 화면 | 행동과 발표 멘트 |
|---|---|---|
| 0:00–1:00 | 홈 | “Mindily는 감정 기록에서 휴식 행동까지 연결하는 AI 친구입니다.” |
| 1:00–3:00 | 감정 일기 | `내일 발표를 잘할 수 있을지 걱정돼요.` 입력, 스트레스 3 선택 후 **AI에게 마음 맡기기** 클릭 |
| 3:00–5:00 | 분석 결과 | 대표 감정 불안과 점수를 보여주고, KcELECTRA API 응답임을 설명 |
| 5:00–6:00 | 무드 미터 | 사용자가 느낀 감정은 모델 결과와 다를 수 있어 **편안한**으로 직접 수정 |
| 6:00–7:30 | 힐링 코치 | 1분 호흡하기와 감정 정리하기를 선택해 실행 |
| 7:30–8:30 | 마음 기록 | 저장된 감정과 스트레스가 주간 기록에 반영되는 흐름 설명 |
| 8:30–9:30 | 기술·데이터 | FastAPI, KcELECTRA, 로컬 저장, `team_motion` 구조 검사 결과 설명 |
| 9:30–10:00 | 한계·다음 단계 | 외부 배포, 5명 테스트, Agent/RAG/장기기억을 다음 단계로 제시 |

## 예상 질문과 답변

- **의료 진단인가요?** 아닙니다. 감정 분류와 자기 성찰을 돕는 서비스이며 진단·치료를 제공하지 않습니다.
- **모델 결과를 사용자가 바꿔도 되나요?** 네. 모델 예측과 사용자의 자기 보고를 별도 필드로 저장합니다.
- **원문은 어디에 저장되나요?** 현재 MVP는 서버에 저장하지 않고 브라우저에 확인 결과만 저장합니다.
- **팀미션 필수 기술은 모두 완료됐나요?** 현재는 KcELECTRA API와 MVP 흐름을 검증했고, Agent/RAG/장기기억·외부 배포·5명 테스트는 후속 단계입니다.

## 장애 대응

API 오류가 나면 서버 상태를 확인하고, 실패 문구를 숨기지 않은 채 입력 내용을 보존한다. 모델이 내려받아지지 않으면 `MINDILY_OFFLINE=1` 점검 모드에서 UI 흐름을 시연하고 실제 모델 검증 결과는 `evidence/api-check.json`으로 제시한다.

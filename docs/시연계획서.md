# 팀미션 시연계획서

## 시연 전 준비

1. [실행 안내](RUN.md)의 `python -m uvicorn server:app --host 127.0.0.1 --port 8010 --no-access-log`로 서버를 실행한다.
2. [Quick Tunnel 안내](QUICK_TUNNEL.md)에 따라 임시 HTTPS 주소를 열고 본인 휴대폰의 모바일 데이터에서 확인한다.
3. 화면 녹화와 개발자 도구 네트워크 탭을 준비한다.
4. Quick Tunnel 시연은 외부 HTTPS로 접속 가능한 **임시 테스트**이며 상시 호스팅이 아님을 발표에서 명확히 말한다.

## 예상 질문과 답변

- **의료 진단인가요?** 아닙니다. 감정 분류와 자기 성찰을 돕는 서비스이며 진단·치료를 제공하지 않습니다.
- **모델 결과를 사용자가 바꿔도 되나요?** 네. 모델 예측과 사용자의 자기 보고를 별도 필드로 저장합니다.
- **원문은 어디에 저장되나요?** 현재 MVP는 서버에 저장하지 않고 브라우저에 확인 결과만 저장합니다.
- **팀미션 필수 기술은 모두 완료됐나요?** 도구 호출형 Agent, 출처 검색·근거 연결(RAG), 동의 기반 선호 기억을 구현하고 임시 HTTPS에서 검증했습니다. 코치 문장은 규칙 기반 fallback이며 외부 LLM 자격증명은 설정하지 않았습니다. 상시 배포와 실제 5명 테스트·피드백 반영은 후속 단계입니다.

## 장애 대응

API 오류가 나면 서버 상태를 확인하고, 실패 문구를 숨기지 않은 채 입력 내용을 보존한다. 모델이 내려받아지지 않으면 `MINDILY_OFFLINE=1` 점검 모드에서 UI 흐름을 시연하고 실제 모델 검증 결과는 `evidence/api-check.json`으로 제시한다.

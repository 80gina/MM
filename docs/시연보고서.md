# 시연보고서

상태: **개발자 자체 점검 완료, 팀 발표 시연·5명 사용자 테스트 미실시**. 아래 ‘확인’은 합성 문장과 임시 HTTPS 브라우저를 사용한 내부 점검이다. 발표 영상이나 실제 참가자 반응으로 간주하지 않는다.

| 흐름 | 현재 확인된 동작 | 남은 범위 |
|---|---|---|
| 홈→감정 일기 | 입력·태그·스트레스 선택, 실제 모델 분석 | 실제 모바일 기기 사용성 평가 |
| 감정 분석→무드 수정 | 6개 분류 점수와 사용자 감정 직접 선택 | 다양한 문장·집단 평가 |
| Agent→힐링 추천 | 도구 호출과 출처 카드, 1분 호흡 | 추천의 실사용 유용성 평가 |
| 확장 추천 | 꽃·나무·필사·음악 검색·취미 카드와 HTTPS 출처 링크 | 향수·위치·맛집 실시간 추천 미구현 |
| 감정 정리하기 | 세 질문 입력, 이 브라우저 저장·새로고침 후 재표시 | 실제 사용자 이해도 평가 |
| 코치 대화 | 규칙 기반 응답·휴식 요청 시 출처 링크 | 자유 생성형 대화·LLM RAG 미구현 |
| 선호 기억 | 동의·조회·삭제, 30일 만료 로직 | 토큰 분실 즉시 삭제·상시 운영 |
| 만족도 조사 | 종료 버튼, 동의 여부 검증, SQLite 저장 테스트 | 실제 사용자 5명 응답 0건 |
| 마음 기록 | 최근 일기 표시, 브라우저 삭제 | 주간·월간 실제 통계·패턴 미구현 |
| 소리로 쉬어가기 | 화면 예시 버튼 | 실제 음악 재생 미구현 |

## 내부 점검 증거

- `evidence/api-check.json`: KcELECTRA 합성 문장 분석.
- `evidence/agent-check.json`: 도구 호출과 출처 표시.
- `evidence/memory-retention-check.json`: 합성 선호의 재시작·만료·삭제.
- `evidence/organizer-check.json`: 감정 정리 화면 저장·새로고침 확인.
- `python test_packaging.py`: Dockerfile 로컬 모듈 포함 여부. 이 컴퓨터에 Docker가 없어 실제 이미지 빌드는 미검증.

## 이 영상이 무엇을 보여주고 무엇을 보여주지 않는가

**실제 그대로인 것**

- 화면·조작·레이아웃 전부 현재 배포본(`dist/`) 그대로입니다.
- 추천 활동 순서, 코치 문장, 인용구·꽃·향은 **실제 모듈**(`healing_knowledge.py`, `rag.py`, `coach_agent.py`, `comfort_knowledge.py`)이 만들어 낸 결과입니다.
- 감정 점수 **불안 0.941**은 실제 모델 호출 측정값입니다 (`evidence/api-check.json`, 2026-09-19).

**밝혀야 할 것**

- 이 영상을 만든 환경에서는 모델 가중치를 내려받을 수 없어, 분류 단계만 위 실측값을 그대로 넣어 재생했습니다.
  즉 **화면과 로직은 실제, 분류 호출만 기록된 실측값 재생**입니다.
- **2026-09-21 기준 배포 서버가 정상 동작합니다.** 같은 문장으로 배포 주소에서 실측한 값은 불안 0.980,
  코치 문장은 `llm_grounded`로 생성됩니다. 영상을 다시 찍으면 이 단서 없이 전부 라이브로 담을 수 있습니다.
- 발표에서 라이브 시연을 하면 이 구분은 필요 없어집니다. 영상은 장애 대비용 백업으로 두는 것을 권합니다.

**직접 라이브로 다시 찍고 싶다면 (5분)**

1. 브라우저에서 **https://yellowmug-mindily.hf.space** 를 엽니다. (서버가 절전 중이면 1~2분 기다립니다.)
2. **Win + Alt + R** (Windows 게임 바 녹화 시작).
3. 위 표 순서대로 조작합니다.
4. **Win + Alt + R** 로 종료 → `영상/캡처` 폴더에 저장됩니다.

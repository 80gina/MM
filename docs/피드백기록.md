# 사용자 피드백 및 개선 기록

상태: 실제 사용자 수집 전. 응답을 임의로 작성하지 않습니다. 2026-09-19 공개 테스트 화면에서 종료 설문을 점수 선택 없이 닫을 수 없던 문제를 발견하고 수정했습니다. 이는 개발자 사용성 점검이며 실제 사용자 피드백 5건에 포함하지 않습니다.

## 질문과 저장 위치
앱 종료 설문은 **전체 만족도 1~5점**과 선택 의견만 동의 후 SQLite에 저장합니다. 분석 이해도·공감도·추천 유용성·접근성 네 항목은 진행자가 [5명 테스트 기록지](사용자테스트기록지.md)에 따로 묻고 익명으로 적습니다. 두 자료를 섞어 앱이 받지 않은 점수를 받았다고 표현하지 않습니다.

개인 일기 원문을 수집하지 않고 피드백 저장 목적을 안내합니다.

| 날짜 | 익명 응답 ID | 의견 | 재현 여부 | 우선순위 | 조치 | 재확인 |
|---|---|---|---|---|---|---|

실제 응답 수·평균·분포는 수집 후 계산합니다.

## 개발자 자체 점검에서 발견한 문제

| 날짜 | 상황 | 원인 | 수정 | 재확인 |
|---|---|---|---|---|
| 2026-09-19 | 만족도 점수를 선택하지 않으면 ‘닫기’를 눌러도 창이 닫히지 않음 | 닫기 버튼이 설문 폼의 기본 제출 버튼으로 처리되어 필수 입력 검사가 실행됨 | 닫기를 일반 버튼으로 변경하고 대화창만 닫도록 연결 | 임시 HTTPS 앱에서 점수 선택 없이 닫힘 확인 |

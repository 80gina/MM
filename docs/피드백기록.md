# 사용자 피드백 및 개선 기록

상태: **실제 사용자 5명 응답은 아직 0건입니다.** 응답을 임의로 작성하지 않습니다.

아래 두 표는 성격이 다릅니다. 위 표는 비어 있고(실사용자), 아래 표는 개발 중 자체 점검과 사용 중 눈에 띈 불편을 고친 기록입니다. **두 표를 합쳐 "피드백 N건을 반영했다"고 표현하지 않습니다.**

## 질문과 저장 위치
앱 종료 설문은 **전체 만족도 1~5점**과 선택 의견만 동의 후 SQLite에 저장합니다. 분석 이해도·공감도·추천 유용성·접근성 네 항목은 진행자가 [5명 테스트 기록지](사용자테스트기록지.md)에 따로 묻고 익명으로 적습니다. 두 자료를 섞어 앱이 받지 않은 점수를 받았다고 표현하지 않습니다.

개인 일기 원문을 수집하지 않고 피드백 저장 목적을 안내합니다.

실제 응답 수·평균·분포는 수집 후 계산합니다.

[실제 사용자 5명 테스트 진행 안내](사용자테스트진행안내.md)에 참가자용 문구와 진행 순서를 적었다. 2026-09-19 자체 확인 시 서버의 앱 만족도 응답은 0건이었다. 합성 Agent·선호 기억 API 테스트는 만족도 응답으로 계산하지 않는다.

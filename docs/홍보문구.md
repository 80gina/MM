## 링크드인 · 개발자 커뮤니티

> **Mindily — 감정 판정과 감정 표현을 분리한 AI 감정 코치**
>
> 감정 판정은 전용 분류 모델(KcELECTRA, 리비전 고정)에 맡겨 점수와 버전을 공개하고,
> 감정 표현은 생성형 AI에 맡기되 검색된 출처 카드 3장 밖으로 나가지 못하게 묶었습니다.
> 일기 원문은 LLM에 전송하지 않고, 생성 실패 시 규칙 기반으로 자동 폴백하며
> 어느 경로로 만들어진 응답인지 `generation` 필드로 항상 공개합니다.
>
> AI Agent · RAG · 생성형 AI · Long-term Memory 네 요소를 각각 테스트 증거와 함께 구현했습니다.
>
> 코드: github.com/80gina/MM
